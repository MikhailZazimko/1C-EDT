# Синхронизация товаров Белка: картинки 150×150

[Скачать ZIP с обработкой](belka_sync_150x150_encrypted.zip?raw=true)

Архив защищён паролем и зашифрован AES-256: исходная обработка содержит
встроенные параметры доступа к API. Пароль передан владельцу в чате,
в репозитории его нет. Открывайте архив через **7-Zip или WinRAR**.

Внутри архива:

- `belka_sync_1_0_0_6_150x150.epf` — обработка версии 1.0.0.6;
- `README.txt` — инструкция;
- `VALIDATION.json` — результаты проверок.

Для файловой базы 1С на Windows с доступным Windows WIA.
Включите флажок «Загружать картинку»: первая картинка товара из API
сохраняется как PNG 150×150 с сохранением пропорций и белыми полями.
Исходные прикреплённые картинки не удаляются; новый вариант назначается основным.

Сборка EPF, повторная распаковка, расчёт геометрии и шесть автоматических
проверок пройдены. Ошибок разбора BSL нет. Запуск в 1С и выполнение Windows WIA
в среде подготовки не проверены. Первую синхронизацию выполняйте в копии базы.
