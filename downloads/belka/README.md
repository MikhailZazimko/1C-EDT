# Синхронизация товаров Белка: картинки 150×150

[Скачать версию 1.0.0.9](belka_sync_150x150_v1_0_0_9_encrypted.zip?raw=true)

Открывайте ZIP через **7-Zip или WinRAR**. Пароль передан владельцу в чате,
в репозитории его нет. Архив зашифрован AES-256: исходная обработка содержит
встроенные параметры доступа к API. Владелец явно разрешил публикацию
зашифрованного архива.

Для файловой базы 1С на Windows с Windows WIA.

В версии 1.0.0.9 исправлена ошибка открытия: для начальной страницы
используется реквизит обработки `ЗаданныйНомерСтраницы`, а имя элемента формы
`НомерСтаринцы` сохраняется для обращений к элементу. Добавлена проверка
соответствия имени реквизита привязке поля из метаданных и выполнение
выражения начальной страницы с этим реквизитом.

В версии 1.0.0.8 добавлена кнопка **«Остановить»**. Загрузка выполняется
короткими этапами, между которыми форма обрабатывает нажатия. Остановка
сохраняет выполненные записи. Кнопка **«Продолжить»** возобновляет работу
с сохранённых страницы и позиции, пока эта форма открыта.

**Текущий сетевой запрос, преобразование или запись должны завершиться.**
Шаг обработки имеет целевой бюджет 2 секунды и не более 50 товаров;
время проверяется после каждого товара. Медленная отдельная операция может
превысить бюджет. Получение страницы API выполняется отдельным шагом.

В заголовке формы показаны состояние, обработанное количество и страница.
Параметры фиксируются на время запуска и паузы. При закрытии формы следующий
шаг отключается, её временное состояние удаляется платформой. Для нового
запуска с начала закройте и откройте обработку; готовые картинки пропускаются.
При обновлении регистрации команда открывает форму с кнопками запуска/остановки.

Оптимизация картинок сохранена: повторное использование по **коллекции + дизайну
(`article` из API) + форме**, без учёта длины, ширины и площади. Готовый PNG
150×150 из базы используется без WIA, старый оригинал уменьшается один раз
на сочетание. У каждого товара своё вложение БСП с готовыми данными.
Пропорции сохраняются, поля белые, оригиналы не удаляются.

В пошаговом режиме в памяти хранится до восьми картинок; остальные повторно
читаются из готовых PNG. WIA создаётся по необходимости внутри активного шага
и освобождается перед сохранением состояния во временное хранилище.

Существующие источники определяются по структуре исходной обработки:
родитель = коллекция, имя = «коллекция дизайн_ширина_длина(площадь)_форма»
или вариант без площади. Неоднозначные и нестандартные имена не используются
как источники; в этом случае картинка берётся из API.

В конце выводятся счётчики и время скачивания, преобразования и записи.
Время ручной паузы исключается при продолжении. Подробности в README внутри ZIP.

Внутри архива:

- `belka_sync_1_0_0_9_150x150.epf`;
- `README.txt`;
- `VALIDATION.json`.

Двенадцать автоматических проверок пройдены; ошибок разбора модуля и формы
BSL нет. Проверены сборка EPF и повторная распаковка, привязка команды кнопки,
остановка/продолжение между страницами без повторов, лимиты шагов и сохранение
курсора при ошибке. Сеть, БСП и WIA в тестах заменены тестовыми обработчиками.
Запуск в 1С, нажатия кнопок, временное хранилище платформы и фактическая скорость
здесь не проверены. Первую проверку выполните в копии базы.
