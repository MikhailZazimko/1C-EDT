# Синхронизация товаров Белка: картинки 150×150

[Скачать версию 1.0.0.11](belka_sync_150x150_v1_0_0_11_encrypted.zip?raw=true)

Откройте ZIP через **7-Zip или WinRAR**. Архив зашифрован AES-256,
поскольку обработка содержит встроенные параметры доступа к API.
Пароль передан владельцу в чате, в репозитории его нет.

Целевая среда: **УТ 11.5.27.107, файловая база Windows**.

## Дозаполнение пустых карточек

В версии 1.0.0.11 добавлена отдельная кнопка **«Дозаполнить пустые карточки»**.
Проход использует уже сохранённые в базе изображения по совпадению
**коллекция + дизайн + цвет + форма**, без учёта ширины, длины и площади.
Весь префикс названия, содержащий коллекцию, дизайн и цвет, сохраняется в ключе.
Размеры разбираются справа, поэтому числовой цвет не принимается за размер.

Дозаполнение обрабатывает всю доступную номенклатуру, включая позиции без
собственного URL картинки и отсутствующие в ответах API. Оно не обращается
к сайту и не создаёт номенклатуру. Флажки синхронизации и номер страницы
на этот режим не влияют.

Заполняются только карточки с пустым реквизитом основной картинки.
Существующие фотографии сохраняются. Нестандартные имена, отсутствие
подходящего изображения и ошибки отражаются в итоговых счётчиках.
PDF и помеченные на удаление карточки/файлы не используются как доноры.
При повреждённом файле пробуются другие доноры с тем же сочетанием признаков.

Каждая карточка получает собственное вложение PNG 150×150 через БСП.
Готовые PNG повторно не сжимаются; при необходимости преобразование
выполняется через Windows WIA. Данные повторно используются из кэша.
Перед записью признаки и отсутствие картинки проверяются ещё раз
в транзакции под блокировкой.

Кнопки **«Остановить»** и **«Продолжить»** работают и для дозаполнения.
Продолжение доступно, пока форма открыта. Повторный запуск пропускает
уже заполненные карточки. Подробная инструкция находится внутри ZIP.

Прежний режим синхронизации, параметры, подготовка картинок 150×150,
авторизация API и предыдущие исправления сохранены.
Дополнительный проход запускается отдельной кнопкой, автоматически
после синхронизации API он не выполняется.

## Проверки

15 автоматических проверок пройдены. Проверены группировка, числовой цвет,
размеры, пропуски и ошибки, резервный донор, повторное использование данных,
остановка и продолжение. EPF собран и повторно распакован без потери кода
и метаданных. Ошибок разбора BSL нет.

В среде подготовки нет платформы 1С и Windows WIA: реальный запуск формы,
БСП, транзакций и WIA в базе пользователя здесь не выполнялся.
