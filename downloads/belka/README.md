# Синхронизация товаров Белка: картинки 150×150

[Скачать версию 1.0.0.7](belka_sync_150x150_v1_0_0_7_encrypted.zip?raw=true)

Открывайте ZIP через **7-Zip или WinRAR**. Пароль передан владельцу в чате,
в репозитории его нет. Архив зашифрован AES-256, поскольку исходная обработка
содержит встроенные параметры доступа к API. Публикация зашифрованного архива
разрешена владельцем.

Для файловой базы 1С на Windows с доступным Windows WIA.
Включите флажок «Загружать картинку».

В версии 1.0.0.7 картинка повторно используется по сочетанию **коллекция + дизайн
(`article` из API) + форма**. Длина, ширина и площадь не учитываются. Для размерных
вариантов скачивание и преобразование выполняются один раз на сочетание.

Уже сохранённый PNG 150×150 используется без скачивания и WIA. Старый оригинал
из базы уменьшается один раз. Источники из базы определяются по структуре исходной
обработки: родитель = коллекция, имя = «коллекция дизайн_ширина_длина(площадь)_форма»
или вариант без площади. Неоднозначные и нестандартные имена не используются
как источники; в этом случае картинка берётся из API.

Фильтры WIA и белый холст создаются один раз на запуск. PNG остаётся ровно
150×150 с сохранением пропорций и белыми полями. У каждого товара сохраняется
собственное вложение БСП с готовыми данными. Оригиналы не удаляются.

Кэш ограничен 64 картинками: после вытеснения читается готовый PNG из базы.
Неудачный запрос картинки не повторяется для каждого размера одной группы
в том же запуске. Повторная попытка возможна при следующем запуске.

В конце выводятся счётчики и время скачивания, преобразования и записи.
Полные успешные ответы JSON заменены кратким итогом страницы.

Внутри архива:

- `belka_sync_1_0_0_7_150x150.epf`;
- `README.txt`;
- `VALIDATION.json`.

Девять автоматических проверок пройдены; ошибок разбора полного модуля BSL нет.
Проверена сборка EPF и повторная распаковка. В тестах кэша для 100 вариантов
одного сочетания выполнены одно скачивание и одно преобразование; для готового
PNG из базы — ни одного. Сеть, БСП и WIA в этих тестах заменены тестовыми
обработчиками. Фактическое время загрузки и выполнение в 1С/Windows здесь
не измерены. Первую проверку выполните в копии базы.
