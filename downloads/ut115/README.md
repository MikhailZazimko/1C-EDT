# Печать номенклатуры для УТ 11.5.27.107

Текущая версия **1.0.2**: [print_ut115_v1_0_2.zip](print_ut115_v1_0_2.zip).
Можно скачать [сам файл .erf](print_ut115_v1_0_2.erf) или
[полные исходники и тесты](print_ut115_sources_v1_0_2.zip).
На странице файла в GitHub выберите
**Download raw file** (значок скачивания), затем распакуйте архив.

Внутри:

- `print_ut115.erf` — тестовый вариант внешнего отчёта;
- `README_RU.md` — инструкция, ограничения и описание переноса.
- `VALIDATION.json` — результаты проверок и контрольная сумма файла отчёта.

В версии 1.0.1 исправлена воспроизведённая ошибка загрузки XDTO
«Отсутствует отображение для префикса: xs». При сериализации отдельного XML
настроек СКД теперь явно сохраняются пространства имён для всех QName типов,
включая `xs:dateTime`, `xs:boolean` и `xs:string`. Добавлена проверка этих
объявлений в каждом XML-блоке после сборки и повторной распаковки `.erf`.
Прошли 7 проверок упаковки и 15 исполняемых проверок расчётов.
В версии 1.0.2 запрос переведён на подтверждённые диагностикой пользователя
поля `ЗапасыИПотребности.ВНаличии` и `РезервироватьНаСкладе`. Сохранена формула
исходного отчёта: наличие минус складской резерв. Составной тип `Склад` ограничен
справочником складов, чтобы исключить подразделения. Прошли 8 проверок упаковки
и контракта метаданных, 15 проверок расчётов и проверка синтаксиса 6 вариантов запроса.
Ссылка `print_ut115.zip` также обновлена на версию 1.0.2.

Вариант собран из предоставленного пользователем отчёта для УТ 10.3.
Исходный печатный макет сохранён; вместо обычной формы используются стандартная
управляемая форма отчёта и параметры СКД. Проверены упаковка, сохранность модуля
и макета, расчёты количества и синтаксис вариантов запроса.

Пользователь подтвердил загрузку формы и диагностики 1.0.1 в УТ 11.5.27.107;
имена полей для 1.0.2 взяты из полученной таблицы. **Количества, единицы и печать
версии 1.0.2 в целевой базе ещё нужно проверить.** После открытия нового файла
снимите **«Диагностика метаданных»**, задайте отборы и нажмите «Сформировать».
Сверьте результат с исходной формулой наличия за вычетом складского резерва.
Полная модель штатной доступности УТ с отдельными блокировками и обособленным
обеспечением не воспроизводится. Расчёт с нулевым резервом вместо отсутствующего
ресурса не выполняется.

Контрольная сумма `.erf` приведена в `VALIDATION.json` внутри архива.
