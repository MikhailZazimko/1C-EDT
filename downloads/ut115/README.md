# Печать номенклатуры для УТ 11.5.27.107

Архив: [print_ut115.zip](print_ut115.zip). На странице ZIP в GitHub выберите
**Download raw file** (значок скачивания), затем распакуйте архив.

Внутри:

- `print_ut115.erf` — тестовый вариант внешнего отчёта;
- `README_RU.md` — инструкция, ограничения и описание переноса.

Вариант собран из предоставленного пользователем отчёта для УТ 10.3.
Исходный печатный макет сохранён; вместо обычной формы используются стандартная
управляемая форма отчёта и параметры СКД. Проверены упаковка, сохранность модуля
и макета, расчёты количества и синтаксис вариантов запроса.

**В целевой базе УТ 11.5.27.107 отчёт пока не запускался.** Структура регистров
свободных остатков и смысл ресурсов резервирования требуют сверки с вашей базой.
Для первого запуска используйте тестовую копию, включите параметр
**«Диагностика метаданных»** и сформируйте результат. При несовпадении структуры
передайте диагностический результат для завершения адаптации; расчёт с нулевым
резервом вместо отсутствующего ресурса не выполняется.
