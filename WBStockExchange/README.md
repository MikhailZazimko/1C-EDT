# Выгрузка остатков WB — 0.1.2

Проверочная внешняя обработка для доработанной УТ 10.3.17.4, платформы 8.3.13.1400, Windows, файловой базы и обычного приложения.

## Получение складов: исправление 0.1.2

Кнопка получения складов теперь сразу сообщает о запуске, показывает среду и адрес GET-запроса, число полученных складов и результат выбора. При HTTP 200 с пустым массивом появляется явное предупреждение, ID не подставляется. Некорректные/пустые ответы не считаются успешным списком. Ошибки показываются и в статусе, и в сообщениях. Журнал `wb-exchange.log` содержит адрес, HTTP-статус и число складов без токенов и без тела ответа.

Самопроверка расширена до 17 проверок: добавлены случаи пустого и корректного списка складов, неверного JSON-типа, пустого тела и записи без ID. Исполнение этих новых проверок в 1С в среде сборки не выполнялось. Клиент подтвердил прохождение 12 предыдущих проверок на версии 0.1.1.

Отсутствие складов в конкретной песочнице пока не установлено. Отключать тестовую среду при использовании тестового токена не следует. После запуска 0.1.2 нужно сообщить точный результат кнопки и при необходимости последние строки журнала без содержимого файла токена.

## Исправление формы

В версии 0.1.0 форма содержала только кнопку с меню пошаговых настроек. В 0.1.1 поля размещены прямо на обычной форме:

- Склад 1С и страна происхождения с выбором из справочников.
- Список нескольких групп номенклатуры; кнопки «Добавить», «Удалить», «Очистить». Вложенные группы включаются.
- Тестовая среда, ID склада WB, пути к локальным файлам токенов и папка обмена.
- Файл профиля, кнопки загрузки и сохранения; профили 0.1.0 совместимы.
- Флажки сопоставления формы без суффикса и разрешения отправки.
- Кнопки предварительного расчета, отправки, получения складов WB и самопроверки.

Откройте новый EPF через «Файл → Открыть» в копии базы. В заголовке должна отображаться версия **0.1.2**. Не открывайте оставшийся локальный файл 0.1.0.

Для первого расчета выберите склад, добавьте группы, при необходимости страну, заполните папку обмена и файлы токенов. Токены в EPF не встроены. Для карточек нужны права чтения контента, для остатков — Marketplace. Сначала оставьте тестовую среду включенной, а разрешение отправки выключенным. Затем нажмите «Рассчитать / просмотр». Результат сохраняется в `preview.xlsx` и открывается отдельным табличным документом.

При получении складов WB можно выбрать один из списка — ID заполнится на форме. Сохранение профиля нужно для повторного ручного и автоматического запуска. Путь к файлу профиля задается на форме.

## Расчет

Свободное количество = остаток минус резерв из доработанного регистра `ОстаткиРезервы`, уже в штуках. Повторного деления площади нет. Если свободно <= 5, передается 0. Если больше 5 — целая часть: 5,9 → 5; 6,3 → 6. Порог проверяется до округления. Артикулы сопоставляются по коллекции, дизайну, цвету, размерам и форме. Несопоставленные товары пропускаются; неоднозначные соответствия и движения с другой длиной блокируют обмен.

Обработка требует реквизитов и регистра указанной доработанной конфигурации; для произвольной типовой УТ не подходит. Доступность конкретного метода в песочнице проверяется отдельно. Отправка выполняется только явной командой и после подтверждения; затем выполняется проверочное чтение WB.

## Проверка 0.1.1

EPF собрана и повторно распакована. Подтверждены 31 элемент формы, привязки 11 полей, наличие всех обработчиков кнопок, координаты в границах окна и совпадение BSL-модулей. BSL Language Server не выявил синтаксических ошибок; предупреждения о Windows COM ожидаемы для этой сборки. Платформа 1С в среде сборки отсутствует: фактическая отрисовка, выбор справочников, компиляция платформой, запросы к базе и авторизованный обмен WB не проверялись.
