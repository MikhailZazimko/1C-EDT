# Выгрузка остатков в Wildberries — 0.1.0

Проверочная внешняя обработка для УТ 10.3.17.4, платформы 8.3.13.1400, обычного приложения, файловой базы Windows. Требует доработанного регистра `ОстаткиРезервы` и реквизитов номенклатуры; для произвольной типовой УТ не подходит.

Откройте `WBStockExchange.epf` через «Файл → Открыть» в копии базы. Кнопка «Остатки WB» открывает меню самопроверки, настройки профиля, списка складов WB, предварительного просмотра и отправки. Токены указываются локальными файлами; в обработку они не встроены.

Выберите склад, несколько групп с вложенными группами и при необходимости страну происхождения. Свободное количество рассчитывается как остаток минус резерв из доработанного регистра. Если свободно <= 5, передается 0. Если больше 5 — целая часть: 5,9 → 5; 6,3 → 6. Порог проверяется до округления. Сопоставление с карточками WB учитывает коллекцию, дизайн, цвет, размеры и форму.

Сначала выберите тестовую среду и оставьте отправку отключенной. Для получения карточек нужны права чтения контента, для изменения остатков — соответствующие права Marketplace. Доступность метода остатков в песочнице с конкретным токеном требует проверки. Изменение остатков выполняется только действием отправки и после подтверждения.

Сборка EPF и совпадение модулей при повторной распаковке проверены; синтаксический анализ выполнен. Компиляция и запуск в 1С, работа с реальными данными, TLS и авторизованный обмен WB не проверялись. Первый запуск — только в копии базы. Это проверочная сборка, а не подтвержденная рабочим запуском версия.
